colonel — the word to delete from the dictionary. This program writes exactly one word, `colonel`, to the output file: the dictionary's most famous spelling lie, spelled nothing like it sounds ("kernel"). Delete it and English finally admits the word is pronounced "kernel".

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
